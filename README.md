# 音の池

しずくを落とすと波紋が広がり、波紋が当たった石が鳴る、ブラウザで遊べる音のおもちゃです。

公開ページ: https://makamaika.github.io/oto-no-ike/

## 遊び方

- 水面をタップすると、しずくが落ちて波紋が広がります。波紋が当たった石は鳴り、その石からも小さな波紋が出て、音がつながっていきます。
- 石は引きずって動かせます。上に置くほど高い音になります（レ・ミ・ソ・ラ・シの陽音階）。石の色の点が、その石の音を表します。
- 下の道具で、しずく・石を置く・石を取る・雨・水音オフ・消音・初期配置を切り替えられます。
- 「水音オフ」にすると、しずくや雨粒が落ちるときの水音だけが消え、石の音は鳴ります。すべての音を消すときは「消音」を使います。
- キーボードでも操作できます。

| キー | 動作 |
| --- | --- |
| `1` | しずく |
| `2` | 石を置く |
| `3` | 石を取る |
| `R` | 雨（ときどき雨粒が落ちる） |
| `W` | 水音オフ（水音だけを消す） |
| `M` | 消音（すべての音を消す） |
| `Space` | しずくを落とす |

石の並びと水音オフの設定は、ブラウザ（localStorage）に保存されます。外部への通信はしません。

## 構成

| パス | 内容 |
| --- | --- |
| `docs/` | 公開するサイト一式。GitHub Pages は main ブランチの `/docs` を公開しています |
| `docs/index.html` | ページ本体 |
| `docs/style.css` | 見た目 |
| `docs/app.js` | 波紋・石・音の処理（Canvas と Web Audio API） |
| `PLAN_*.md` | 作業の計画と結果 |

依存パッケージやビルドの手順はありません。`docs/` の中を編集して main にプッシュすると、GitHub Pages に反映されます。

ページには CSP（Content Security Policy）を meta タグで設定していて、自分のサイトにあるスクリプト・CSS・画像だけを読み込めます。

## ローカルで確認する

CSP の都合で、`docs/index.html` をファイルとして直接開くと、ブラウザによってはスクリプトが読み込まれません。一時的な Web サーバーで確認してください（ポート番号は空いているものに変えてかまいません）。

```bash
python -m http.server 8765 --bind 127.0.0.1 --directory docs
```

起動したら http://127.0.0.1:8765/ を開きます。終わったら Ctrl+C で止めます。
